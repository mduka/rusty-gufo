# Qwen3-TTS experiments

What has been tried on this engine for Qwen3-TTS, so that later optimization
rounds do not try it again. Above all it keeps what did not help or made
things worse, with the measurement and the reason; what the code already does
gets a line. Gufo's
[experiments](https://github.com/gufo-org/gufo/blob/v0.28.1/docs/models/qwen3-tts/EXPERIMENTS.md)
keep the same for its C++ engine, whose kernels this engine runs: read both
before an optimization round. Ideas not tried yet come last. The core and what
spans models are in [optimizations](../../OPTIMIZATIONS.md).

Nothing has been tried on this engine yet.
